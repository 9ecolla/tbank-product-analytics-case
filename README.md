# A/B-тест новой формы оплаты ЖКХ

**Руслан Ахметов · продуктовая аналитика**

Анализ учебного кейса: новая форма с упрощённым заполнением реквизитов,
тест за 1–30 апреля 2024 года. Принимается допущение: A — старая форма, B — новая.

## Результат

Рекомендация — внедрение новой формы с поэтапным расширением охвата и контролем
ошибок оплаты, повторных списаний и обращений в поддержку.

| Показатель | A | B |
|---|---:|---:|
| Назначено клиентов | 752 | 751 |
| Попыток после очистки | 1 308 | 1 351 |
| Успешных оплат | 651 | 870 |
| Конверсия попыток | 49,77% | 64,40% |

Эффект **+14,63 п.п.**, относительное изменение **+29,39%**.
95% кластерный bootstrap ДИ: **[+10,96; +18,28] п.п.**, permutation p < 0,001.
При сохранении эффекта это около **146 дополнительных успешных попыток на 1 000 открытий**,
а не оценка дополнительных уникальных клиентов или выручки.

## Почему метод учитывает устройство эксперимента

Основная метрика: число успешных попыток / число открытий формы.
Назначение в A/B проводилось по клиентам; после очистки у 760 клиентов несколько попыток.
При bootstrap пересэмплируются целые клиенты, а при перестановочном тесте метки
назначаются клиентам с сохранением размеров групп. В обоих случаях сохраняется
отношение сумм, а не среднее индивидуальных конверсий. По 20 000 повторов;
bootstrap seed=42, permutation seed=43, α=0,05.

## Проверки устойчивости

- Альтернативная обработка конфликта групп: основной эффект остаётся около +14,59 п.п.
- При общем составе устройств эффект **+14,54 п.п.**
- Доля клиентов с оплатой среди открывавших: **65,65% → 80,40%**.
- Отдельно рассмотрены первая попытка клиента и доля успешно оплативших среди всех назначенных.
- Дельта-метод даёт независимую аналитическую проверку доверительного интервала.

Дополнительные метрики и разрезы используются для диагностики, а не для выбора
«значимого» результата. Переходы между промежуточными шагами не интерпретируются
как отдельные причинные эффекты: состав дошедших до шага может зависеть от варианта.

## Данные и воспроизведение

Python **3.12**. Исходный Excel и сохранённая страница задания не публикуются.
Владельцу исходного файла для повтора расчётов нужно:

1. Скачать этот репозиторий и установить зависимости: `python -m pip install -r requirements.txt`.
2. Положить исходный файл в `data/dannye-dlia-keisa-po-pa-cebbefc3-5b29-4f88-b6d4-3336c88d743f.xlsx`.
   Также поддерживается размещение рядом с notebook или в Downloads.
3. Открыть `analysis.ipynb` в Jupyter/VS Code, выбрать окружение с зависимостями
   и выполнить **Restart Kernel → Run All**.

Будет сформирован `report.pdf`. Промежуточные изображения и контрольные результаты
сохраняются в игнорируемой `.artifacts/`. **Графики и две итоговые таблицы в PDF —
те же изображения, которые выведены в notebook.** Внешнего скрипта для анализа не требуется.
Без исходного Excel результаты можно изучить в сохранённых выводах notebook и в PDF.

## Ограничения

Соответствие A/B, ожидаемый сплит 50/50 и отсутствие стратификации — допущения.
Нет сумм платежей, стоимости изменений и защитных метрик. Завершения после апреля
не наблюдаются. Статистический рост конверсии сам по себе не устанавливает
экономическую выгоду и безопасность новой формы.
